**Десктопное приложение и CLI Sync-in обеспечивают локальную синхронизацию и доступ из командной строки к серверам Sync-in.**

Синхронизируйте файлы между рабочими станциями, серверами и автоматизированными средами, используя те же правила доступа, механизмы аутентификации и модели совместной работы, что и в Sync-in Server.

Sync-in Desktop предназначен для ежедневного использования на рабочей станции, а CLI подходит для автоматизации, написания скриптов, выполнения запланированных задач, CI/CD-конвейеров и развертываний без графического интерфейса (headless).

## Функции

- 💻 Десктопное приложение для Windows, macOS и Linux
- 🌐 Поддержка нескольких серверов из одного локального клиента
- 🔁 Однонаправленные и двунаправленные сценарии синхронизации
- 🛡️ Безопасный режим синхронизации на основе контрольных сумм для усиленной проверки целостности
- ⚡ Быстрый режим синхронизации на основе метаданных для облегченной синхронизации
- 📆 Запланированная синхронизация для регулярных задач
- 🎯 Фильтры включения и исключения для файлов и папок
- 🧪 Предпросмотр синхронизации для имитации операций перед их фактическим выполнением
- 📥 Встроенный менеджер загрузок и передачи файлов
- 👀 Мониторинг передачи данных в реальном времени, журналы (логи) и отслеживание синхронизации
- 🤖 Пошаговый мастер настройки для упрощения первоначального развертывания
- 🔐 Аутентификация, совместимая с механизмами идентификации Sync-in Server
- 🔄 Автоматические фоновые обновления
- 📟 Поддержка CLI для автоматизации, скриптов, задач cron, CI/CD и headless-сред
